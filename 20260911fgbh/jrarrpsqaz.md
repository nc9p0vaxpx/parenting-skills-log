# 文献综述 | 衰老分子机制与抗衰老策略(一)

> 更新时间：2026-09-11 (UTC+8)

未来几十年，全球范围内老龄化将成为一个主要的社会问题。在老化过程中，老年人的身体组织和器官会发生功能衰退或恶化，从而增加他们患与年龄相关的疾病的风险，缩短他们的健康寿命，这给全球各国带来了巨大的养老金、医疗费用和保健方面的财政压力。因此，探索衰老的生物学本质，寻找安全有效的干预策略来积极调节健康状况，并延长老年人的健康寿命，对于减轻全球养老金负担和促进健康老龄化至关重要。
衰老是一个复杂而多方面的过程，涉及多种相互关联的分子机制和细胞系统。从表型上看，生物衰老过程伴随着细胞功能逐渐丧失和多个组织系统的系统性恶化，导致易感于与衰老相关的疾病。新兴证据表明，衰老与**端粒消耗**、**DNA损伤**、**线粒体功能障碍**、**烟酰胺腺嘌呤二核苷酸水平下降**、**宏观自噬受损**、**干细胞耗竭**、**炎症**、**蛋白质平衡失调**、**营养感知紊乱**、**细胞间通讯改变**和**菌群失调**密切相关。这些与年龄相关的变化可以通过干预策略来缓解，如**限制热量摄入**、**改善睡眠质量**、**增加体力活动**和**针对长寿基因进行靶向治疗**。
**一：总论**
衰老是一种渐进的退化状态，既可以是生理性的，也可以是病理性的。生理性衰老在许多物种中都有观察到，是一种在成熟后发生的退化过程，包括端粒耗竭、DNA损伤、线粒体功能障碍、烟酰胺腺嘌呤二核苷酸（NAD+）水平下降等。受损的巨自噬、干细胞耗竭、炎症、蛋白质平衡失调、营养感应紊乱、细胞间通讯异常以及菌群失调，从而导致系统性功能下降。重要的是，这些变化是分散的、相互关联的，而不是相互独立的。病理性衰老包括老年病理性衰老变化，是由各种外部因素引起的，如心血管疾病、脑血管疾病、退行性关节疾病、糖尿病、帕金森病、阿尔茨海默病、癌症以及多个器官功能的退化。这些衰老引起的细胞生理和病理变化可以反映出其背后的营养感应、细胞间通讯、蛋白质稳定性、表观遗传学和DNA损伤修复的分子异常，导致遗传不稳定和损伤。进一步了解衰老过程中涉及的不同分子机制对于预防衰老和延长寿命至关重要。
近年来，已经进行了大量的动物和临床实验，研究导致衰老的因素，如衰老生物体的形态学和病理学变化以及功能衰退。事实上，**生物学年龄**和**时间年龄**之间的一些差异反映了衰老过程中已知的加速或减速程序的有效性，这些程序是衰老过程的生物标志物。研究人员逐渐从传统的衡量衰老的方法（包括呼吸、感觉、心理运动和认知水平的最大能量消耗）扩展到现代生物技术方法，如基因组学、表观基因组学、转录组学、蛋白质组学和代谢组学。这些技术可能对评估健康退化的时空模式和抗衰老策略的有效性具有重要意义。

**二：DNA损伤与衰老**

**DNA损伤是导致基因组不稳定性、表观遗传变化、蛋白质应激、线粒体功能受损和端粒功能障碍的主要内部因素**。DNA损伤细胞的持续积累会触发细胞死亡和衰老，最终导致细胞和组织的慢性炎症、功能丧失、萎缩和疾病。
**DNA损伤的分子机制**
**基因组不稳定性表现为DNA序列的永久和可传递性改变**。由内在不稳定基因组引起的DNA损伤包括自发脱氨基、水解和许多其他化学改变，如不同类型的断裂、碱基位置变化、缺口、DNA-蛋白交联和其他微妙的化学修饰。异常的DNA结构（如G-四链体、R-环和持久的单链区域），以及DNA转录、复制和重组过程中的异常中间体（如停滞的转录、复制和重组复合物），被认为是DNA损伤的表型。**由DNA不稳定性引起的基因组突变对细胞功能产生不利影响，是癌症和遗传疾病的主要原因**。然而，DNA不稳定性也是物种进化中最重要的基质。**通过持续修复高度复杂的DNA修复和DNA损伤应答（DDR）系统，维持DNA完整性，以对抗遗传DNA信息的随时间侵蚀和破坏**。渐进性端粒缩短是加速衰老过程的另一个重要因素。

**DNA损伤是年龄相关表观遗传变化的主要驱动因素**。表观基因组，包括DNA甲基化和组蛋白修饰，在体细胞的整个生命周期中都是不稳定的。DNA损伤导致持久的染色质变化，富集老化增强的DNA片段（DNA疤痕）在衰老细胞中。持久的DNA损伤和与修复相关的细胞生理效应可能留下表观遗传标记，导致细胞间表观遗传异质性。转录在衰老细胞中的变化明显大于年轻细胞。因此，DDR可能是导致表观遗传变化的主要原因，破坏基因表达控制，导致体细胞异质性和整体功能的随时间下降。
**DNA损伤与衰老的关系**
在衰老过程中，众多外源性和内源性的基因毒素、光老化和组织中的机械应力不断引起DNA损伤。每天在哺乳动物细胞中大约发生105次DNA损伤事件，尽管大部分DNA损伤能够有效地被切除或修复。值得注意的是，一小部分逃脱了DNA损伤检测和修复系统，随后导致修复失败或修复错误。许多使用哺乳动物模型的研究已经证实了**DNA损伤与衰老之间的密不可分的联系**。**随着衰老的进行，DNA修复能力逐渐下降，增加的基因组不稳定性分子表型成为衰老的主要标志**。DNA损伤标志物在与年龄相关的疾病患者中被发现，如心血管疾病、阿尔茨海默病和癌症，表明DNA损伤与这些疾病的发生直接相关。具有DNA修复蛋白的遗传或获得性缺陷的患者也表现出早衰的特征，而DNA修复系统中缺陷的位置的差异可能导致不同器官的早衰。具体而言，RecQ解旋酶在DNA重组、复制、修复和端粒维护中起重要作用，其突变可能增加Werner、Bloom和Rothmund-Thomson综合征的发病率。全局基因组核苷酸切除修复缺陷导致皮肤癌易感性增加千倍，并可能加速神经退行性疾病。受损的转录耦合修复机制可以引起典型的与年龄相关的病理变化，如神经退行性疾病、骨质疏松和动脉粥样硬化。Hutchinson-Gilford早衰症与核基因组不稳定性、DNA双链断裂修复缺陷导致毛细血管扩张和尼姆根断裂综合征，以及DNA交联修复缺陷导致贫血有关。此外，由线粒体缺陷引起的DNA损伤是影响多个器官的一类进行性疾病的另一个潜在因素。

总的来说，DNA损伤修复系统的缺陷直接导致基因组突变的持续积累，这是人类许多分段型早衰的基础，暗示了基因组完整性与衰老之间的密切关联。尽管在研究DNA损伤与衰老之间的机制联系方面取得了相当大的进展，但仍有许多问题需要进一步探索DNA损伤如何影响老年人疾病的具体分子机制。因此，从根本上解决衰老过程并对抗与年龄相关的疾病对于探索DNA损伤与抗衰老效应之间的关系至关重要。

**三：衰老与端粒磨损**
**端粒是存在于真核细胞线性染色体末端的DNA-蛋白复合物，它们维持染色体完整性，控制细胞分裂周期，并对生物的健康寿命和繁殖至关重要**。早在20世纪60年代，一位名叫莱昂纳多·海弗利克的科学家发现培养的人类成纤维细胞具有有限且可重复的复制能力，并受细胞自主机制的调控。即使寒冷停止了细胞分裂，一旦温度再次升高，细胞在冻结之前将继续分裂，直到停止分裂后的50次。海弗里克意识到细胞有一种深层次的内部机制来控制它们的分裂次数。在20世纪70年代，奥洛夫尼科夫和沃森通过观察线性DNA复制中的不对称性，发现了“末端复制问题”，并预测每次细胞分裂都会导致滞后链末端的染色体DNA丢失，最终导致染色体逐渐缩短。有限的端粒长度储备是细胞增殖和存活的障碍，而端粒功能的丧失与年龄相关的功能衰退和疾病发病率增加密切相关。**端粒和端粒酶的结构**
端粒末端保护在从低等多细胞生物到高等多细胞生物中具有高度保守性。**在结构上，端粒由串联的重复核苷酸序列3'-[TTAGGG]-5'组成，长度从几个到几十个碱基不等，3'端以富含鸟嘌呤核苷酸的单链终止，形成“帽状结构”**。端粒由一种名为shelterin复合物的特殊蛋白覆盖，该复合物是由六个蛋白亚单位（TRF1、TRF2、TPP1、POT1、TIN2和RAP1）的多聚体组成，它们共同保护染色体并调节端粒长度。端粒和shelterin复合物形成复杂的高级结构，通过介导非同源末端连接来保护DNA修复程序免受末端融合的影响，最终参与端粒的帽状结构、保护和调控。相应地，这六个蛋白组分的突变可能破坏shelterin-端粒复合物，导致末端融合和过早衰老。具体来说，**端粒维持与TRF1的正常表达密不可分**。TRF1的缺失会导致端粒DNA形成易碎位点表型，而TRF1的过度表达会影响端粒酶与端粒末端的结合，最终导致端粒缩短。TRF2将端粒DNA折叠成T环，抑制共济失调性毛细血管扩张依赖的染色体末端DNA损伤应答，并抑制末端对末端染色体融合和经典同源末端连接。此外，TIN2在shelterin复合物中起到连接作用，形成不同shelterin蛋白之间的桥梁。TIN2突变不会干扰其他shelterin组分在端粒上的空间结构；然而，TIN2-R282H突变会激活端粒DNA损伤信号，导致与端粒酶活性相关的端粒不稳定性，最终导致细胞过早衰老表型。不受控制的POT1会影响端粒酶与端粒末端的结合，导致端粒缩短。TPP1与端粒酶反转录酶（TERT）相互作用，招募端粒酶，其丧失会引发强烈的端粒DNA损伤应答。Rap1是一个关键的端粒帽蛋白，可以防止非同源末端连接和端粒融合，其过度表达会导致组蛋白丢失并加速细胞衰老。总的来说，端粒的生物功能完整性取决于端粒和shelterin复合物的相互作用，它们共同调节端粒长度和细胞生命周期。值得注意的是，通常仅仅缩短的端粒本身并不会驱动衰老（生物学），但如果端粒缩短到被视为双链DNA断裂，则这些端粒将招募DNA损伤应答并将细胞引入正常的凋亡或衰老程序。

端粒酶是由两个基本亚单位组成的核酸酶：**TERT和端粒酶RNA组分（TERC）**。TERC中的Cajal小体蛋白1的H/ACA结构域与端粒酶结合形成端粒酶Cajal小体蛋白1，该复合物催化端粒酶活性并将端粒酶转运到端粒末端。此外，多个核心蛋白组分，包括dyskerin、NHP2、NOP10和GAR1，对端粒酶的正常催化功能至关重要。通常情况下，端粒酶在未分化的干细胞和生殖细胞、皮肤、肠道、造血系统、毛囊和睾丸中丰富表达。然而，在神经母细胞、成纤维细胞、心肌细胞和精子细胞等分化的成年细胞中，端粒酶的表达极低或不可检测。在生殖细胞系和一些干细胞中，端粒酶可以弥补端粒复制的损失，这种损失随着细胞分裂而减少。端粒酶在大多数体细胞早期发育阶段是沉默的，限制细胞分裂的次数，直到端粒变得非常短。端粒缩短在衰老过程中的致病性是一种特征性的拮抗多效性效应。一方面，端粒功能失调的细胞容易发生基因组不稳定性，并可能成为癌细胞。另一方面，端粒的正常复制缩短可以限制无限制的细胞增殖，并诱导细胞凋亡或衰老，从而防止肿瘤的形成。Robinson等人发现了一种帮助端粒保持长度的方法，称为端粒长度的可选延长（ALT）。在骨肉瘤和面包癌细胞系中，端粒长度延长与抑制肿瘤生长的潜在关系在通过ALT维持端粒长度的细胞系中巧妙地编排。即使端粒长度延长，肿瘤也可以被抑制。

**在正常细胞中，维持适当的端粒长度需要完整的端粒结构和高度复杂的端粒酶调控**。然而，端粒和端粒酶复合物中的每个相关蛋白都容易受到组织微环境中不可控因素的影响。然而，关于如何感知、表达和招募端粒酶复合物到端粒末端进行功能调控的问题仍存在一些科学争议，以确定端粒和端粒酶在系统衰老和退行性疾病发病机制中的作用。最近，端粒功能失调被描述为衰老细胞的分子特征，而端粒功能丧失与基因组不稳定性、DNA损伤应答和与年龄相关的健康下降密切相关。最重要的是，衰老过程中的端粒功能失调可以放大和驱动其他衰老机制和早衰综合征。
**端粒和端粒酶功能失调与衰老的关系**
有机体细胞的端粒储备是有限的，而端粒功能的丧失与与年龄相关的适应性下降密切相关。优秀的端粒和端粒酶结构对于确保母体和后代的正常生理功能至关重要，它们的完整性具有一定的遗传代际效应。连续几代交叉繁殖的TERT敲除小鼠，后代的端粒逐渐缩短，最终在第三代发展出端粒功能失调。此外，低端粒酶水平和持续的组织更新导致高增殖组织的祖细胞中几十年的渐进性端粒消耗，包括造血系统、胃肠道和皮肤。过度的端粒消耗最终触发细胞周期阻滞、凋亡、分化障碍和衰老等DNA损伤应答。值得注意的是，随着衰老过程的进行，心脏、大脑和肝脏等低增殖组织可能会受到活性氧（ROS）的影响，进一步诱导端粒序列损伤、端粒消耗和解帽。因此，上述端粒特性使其成为衰老生物学的焦点。

端粒缩短至临界长度会导致细胞复制性衰老。染色体端粒会随着DNA复制逐渐缩短。当端粒达到临界长度时，它们无法结合足够的覆盖端粒的蛋白质，被视为裸露的DNA末端。一个或几个非常短的端粒足以触发DNA损伤反应，并诱导细胞周期抑制标记物p53和p21的过度表达，从而强制抑制细胞增殖。积累的衰老细胞分泌一系列复杂的促炎细胞因子，称为衰老相关分泌表型（SASP），包括白细胞介素、白细胞介素趋化因子、蛋白酶和生长因子。SASP改变细胞外基质的组成，并将衰老表型传播给周围细胞，导致全身慢性炎症。有趣的是，持续的端粒凝聚保护了老化细胞免受过早衰老的影响。因此，与端粒功能障碍相关的DNA损伤反应信号事件是细胞命运和有机体衰老的关键决定因素。

总之，端粒和端粒酶在推动衰老和许多重大人类疾病的核心机制中起着重要作用。然而，仍然存在许多知识空白，例如澄清调控端粒酶表达和活性的机制、TERT的非经典功能以及端粒功能障碍、炎症、纤维化和退行性疾病之间的相互作用。因此，迫切需要开发端粒酶激活剂来治疗衰老和与年龄相关的疾病，通过修复端粒和端粒酶的损伤来预防和治疗由端粒缩短引起的致命疾病。
