# 医讲堂丨大雪节气了，你还在露脚踝吗？

> 更新时间：2026-09-16 (UTC+8)

大雪节气，天气越来越冷，却有不少人依然穿九分裤、船袜而露着脚踝。这种打扮虽然很fashion，但却存在着很大的健康隐患。

**冬天露脚踝有哪些健康隐患？**

脚踝是人体较为脆弱的地方，薄弱的皮下脂肪保温性很差。如不注意脚踝的保暖，容易导致寒邪入络，引发疾病。中医认为，脚踝是人体三条阴经、三条阳经的会聚点，被寒邪所侵后，轻者脾经、胃经受寒，脾胃不开；重者肝经、肾经受寒，出现肝郁，特别是女孩子容易出现妇科病。

中医讲究取类比象，脚踝类比手腕、颈部，脚踝受寒邪后，会出现四肢关节痛及颈椎病。把脚踝露在外面，特别在寒冷天气，容易导致寒湿入络，引发关节炎和风湿痛。这些症状未必会立马发作，但可能“潜伏”至中年。

**脚踝两大穴位保健康**

1

// **太溪穴**

该穴是足少阴肾经的原穴，可以说是肾经经气发起和最旺的地方。古人十分注意该穴的重要性，作为“回阳九穴”之一记载于我国古代的医学典籍中，具有提高肾功能的作用。平时我们可以通过对太溪穴的按摩刺激来激活人体肾经的经气，以滋阴补肾、滋养先天之本。

临床上，常用太溪穴治疗头痛、耳鸣、咳嗽、月经不调、小便频数、内踝肿痛、足跟痛、手脚冰凉、失眠、健忘等。

2

// **三阴交穴**

该穴是人体三条足阴经的交汇处，即足太阴脾经、足厥阴肝经、足少阴肾经。三阴交穴是人体十总穴之一。所谓“妇科三阴交”，顾名思义此穴对于妇科疾病甚有疗效。每天按揉此穴15分钟，不仅能保养子宫和卵巢，帮助调节月经，同时对于皮肤还有很大帮助。另外，三阴交还能调治脾胃虚弱、消化不良、腹胀腹泻、全身水肿、眼袋浮肿、小便不利、失眠等症。

脚踝暴露，这两大穴位受寒，诱发疾病，为“美丽冻人”而付出健康的代价，得不偿失，因此，提醒大家在追求美的同时，更要注重身体健康！
