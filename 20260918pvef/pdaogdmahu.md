# 先天性双侧输精管缺如试管婴儿做二代好还是三代

> 更新时间：2026-09-18 (UTC+8)

我和妻子结婚2年了，两个人都是事业型的，最开始因为工作忙没有要小孩。去年的时候开始备孕，然后做了孕前检查，我老公检查出先天性输精管缺如，医建议去做试管。当时还没考虑好，今年打算做试管婴儿了，有没有遇到同样情况的姐妹，请问大家这个情况是做二代还是三代试管好？

男性不孕问题越来越多，很多人还不清楚输精管缺如是什么，输精管缺如是一种性连锁隐性遗传病，是男性殖系统的一种先天性畸形，是导致男性不育的一个重要病因。先天性双侧输精管缺如试管婴儿做二代好还是三代，如果男方仅表现先天性输精管缺如，没有CFTR基因突变的情况，可以考虑做二代试管，如果携带有CFTR突变基因，建议做第三代试管。

先天性双侧输精管缺如，不论是做第二代还是第三代，可以明确的是该患疾病可以通过试管婴儿技术来育宝宝的。至于该选择几代试管，可以具体问题具体分析。

1. 目前先天性双侧输精管缺如无法治愈，因为输精管无法恢复，可以依靠殖辅助技术来完成育；

2. 如果说先天性的输精管缺如，同时又没有CFTR基因突变就可以考虑做第二代试管婴儿；

3. CFTR突变基因引起的囊性纤维化病是一种染色体隐性遗传病，如果夫妻双方均为携带者，后代患病的概率就很高，可以选择第三代试管婴儿；

4. 如果女方不是携带者，那后代可能为携带者。做第三代试管婴儿可以通过基因筛查技术淘汰有异常的胚胎，健康的宝宝。

在试管婴儿助孕治疗中，不同的患者不孕的症状与原因多种多样，不同的病因采取的助孕技术不同。先天性双侧输精管缺如试管婴儿选择二代好还是三代好，需要大家从实际情况判断。如果患者没有CFTR基因突变，第二代试管婴儿就可以解决育难题，如果男方携带有CFTR突变基因，不管女方是否携带，都建议做第三代试管婴儿。
